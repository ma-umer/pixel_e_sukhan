# 📜 Pixel-e-Sukhan

### Bringing Urdu literature to your desktop, one pixel at a time.

What if your desktop icons weren't ordinary folders and shortcuts, but little pixelated portraits of the people who shaped Urdu literature?

**Pixel-e-Sukhan** is a creative project celebrating Urdu poets, writers, satirists and intellectuals through 8-bit pixel art.

From Manto's unapologetic storytelling to Mushtaq Ahmed Yousifi's extraordinary humour, this collection brings a little literary character to your everyday desktop.

*Because even your desktop deserves a little adab.*

## 🎨 How It Was Created

The collection was created using AI-assisted image generation and simple image-processing steps.

The workflow:

**Step 1 — Generate**

Create a sticker sheet of literary characters in an 8-bit pixel-art style with a transparent background.

**Step 2 — Extract**

Separate the characters into individual PNG files, each 256 × 256 pixels.

**Step 3 — Convert**

Convert the illustrations into:
- `.ico` files for Windows.
- `.icns` files for macOS.

**Step 4 — Customise**

Apply the icons to desktop folders and shortcuts.

The original prompts used for this process are included in the repository.

## 💻 Installation Guide

### 🪟 Windows

1. Download the `Windows_ICO` folder.
2. Save your ICO files in a permanent location on your computer (for example, `Documents/Icons`).
3. Right-click the folder you want to customise and select **Properties**.
4. Open the **Customize** tab.
5. Click **Change Icon**.
6. Click **Browse** and select your preferred `.ico` file.
7. Click **OK**, then **Apply**.

**Note:** Do not move or delete the folder containing your icons after applying them, as Windows may lose the icon references.

### 🍎 macOS

1. Download the `Mac_ICNS` folder.
2. Open your chosen icon file in Preview.
3. Press `Cmd + A` to select the image.
4. Press `Cmd + C` to copy it.
5. Right-click the folder you want to customise and select **Get Info**.
6. Click the small folder icon at the top-left of the information window.
7. Press `Cmd + V` to apply the new icon.

## ✍️ Image Generation Prompts

The project includes the prompts used to generate and process the pixel-art characters.

**Prompt 1 — Sticker Sheet Generation**

```text
Make a sticker sheet of [YOUR IDEA] in 8-bit pixel art style.

Keep each character separate with space around it.
The sticker sheet should have a transparent background.
```

**Prompt 2 — Character Extraction and Conversion**

```text
Cut this sheet into separate PNG files, one per character,
each 256 x 256 pixels with a transparent background.

Keep the pixels sharp, with no blurring.

Then convert each one into an ICO file for Windows
and an ICNS file for Mac, and name each file
after its character.
```

*Side note: If automated extraction or conversion doesn't work, this process can also be completed manually.*
